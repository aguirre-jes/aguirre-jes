# Hey, I'm Jesús Aguirre 👋

## Solution Architect | Cloud Native | Kubernetes | AWS | Java

I work at the intersection of **solution architecture, cloud native technologies, and software engineering**.

Currently, I'm a Solution Architect at Copa Airlines, an AWS Community Builder (Containers), and the leader of Panama Java User Group.

I'm interested in how we design, build, and operate systems in real-world environments — exploring technologies, experimenting with different approaches, and sharing what I learn along the way.

I believe good engineering is less about choosing the latest technology and more about understanding the problem, evaluating trade-offs, and making informed decisions.

### Some topics I enjoy exploring

- Cloud Native architectures and distributed systems
- Kubernetes, Amazon EKS and containers
- Application architecture and modernization
- Java / JVM ecosystems
- Platform Engineering and Developer Experience
- Observability, scalability, security and reliability
- Infrastructure as Code and automation
